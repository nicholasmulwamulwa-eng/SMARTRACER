# Play Store Checklist

This document lists key items you need to prepare before uploading to Google Play Console.

- App name and description
- App icon (high resolution)
- Feature graphic and promotional images
- Screenshots (phone/tablet)
- Privacy policy URL
- Data safety form
- Target and minimum SDK levels
- Signed Android App Bundle (.aab)
- Content rating
- Ads declaration (if applicable)

Do not publish any secrets in this repository. Follow Google Play guidance for store listing assets and requirements.
