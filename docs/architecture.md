# Project architecture

This file explains the initial folder structure and where to add new content.

/ (project root)
- project.godot                - Godot project file
- assets/                     - art, models, textures, audio
- scenes/                     - Godot scenes (main, menus, tracks, cars)
- scripts/                    - GDScript code
- data/                       - JSON or resource files for cars, tracks, upgrades
- shaders/                    - custom shaders
- docs/                       - documentation and release guides

Autoloads (to add later):
- RaceManager
- PlayerData
- AudioManager

Follow the PHASE plan in the main project prompt to iterate incrementally.
